# Expense-Tracker
 I developed a *Command-Line Expense Tracker* 💻

🔹 Key Features:
* Add, view, update, and delete expenses (CRUD operations)
* Category-wise expense tracking (Food, Travel, etc.)
* Total spending calculation
* Data stored using file handling (JSON) for persistence

🔹 Concepts I applied:
* Loops & Conditional Statements
* Functions & Arguments
* Lists and Dictionaries
* File Handling (read/write data)
* Basic Data Organization & Problem Solving
